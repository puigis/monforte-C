# Monforte C

Seguiment del C.B. Monforte "C" a la Lliga Catalana de Tres Bandes.

- `index.html`: l'app (es publica amb GitHub Pages).
- `data/data.json`: dades generades automàticament.
- `data/inicials.json`: promigs inicials manuals (tenen prioritat sobre el rànquing).
- `scripts/actualitza.py`: llegeix la web pública de la FCB. S'executa sol diumenge, dilluns i dimecres.
